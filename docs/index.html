Key Features

High-speed extraction, precision clip trimming, and 100% local privacy.

Precision Clip Cutter & Subtitle Sync

Trim exact Start Time to End Time (MM:SS or HH:MM:SS) 3x–5x faster with -preset ultrafast. Automatically trims and time-shifts .vtt/.srt subtitles to 00:00 and strips [%(id)s] while preserving [clip ...] tags.

Sub-Second oEmbed Preview (~0.2s)

Resolves title, thumbnail, and channel in ~0.2s via oEmbed and a 64-entry LRU cache while fetching full duration in the background. Automatically cancels active previews when a download starts.

Unlimited Progressive Playlists

Removes the 100-video cap and streams playlists of any size in 500ms DocumentFragment batches. Download all or selected items using smart range compression (1-2,4-500).

Multi-Language Subtitles (CC) & Cover Art

Embeds original spoken language captions (.*-orig, YouTube CC style) plus manual Bangla (bn) and English (en) subtitles while skipping robotic translations (skip=translated_subs). Embeds cover art into MP4, MKV, MP3, and M4A.

Android Background Service & Share Menu

Powered by Android 14 dataSync Foreground Service and WakeLock for screen-off downloads. Rich notifications show live MB/s speed and ETA with one-tap Play and Open Folder actions.

Play Protect Safe Auto-Updater

Uses Android's native DownloadManager without REQUEST_INSTALL_PACKAGES permission, complete with automatic file renaming and old-APK cleanup.

Unlimited Progressive Playlist Engine

How playlists with 100, 500, or 2,000+ videos load and download without UI lag.

1. Background Streaming & InnerTube Pagination

  • • Removed 100-Video Cap: Eliminated --playlist-end 100 across server.py and MainActivity.kt in favor of progressive background streaming.
  • • YouTube InnerTube Continuation: Forwards session-bound visitorData (X-Goog-Visitor-Id), INNERTUBE_API_KEY, and Cookies to /youtubei/v1/browse.
  • • 500ms Batch DOM Rendering: Appends 38 items per 500ms tick via DocumentFragment (38 → 76 → 114 ...) without resetting scroll position.

2. Smart Range Compression & Auto-Cancel

  • • Smart Range Compression (compressPlaylistIndices): Skipping item 3 in a 500-video playlist compacts the selection into 1-2,4-500.
  • • Auto-Stop Preview on Download (/api/cancel-preview): Starting a download immediately terminates any running background preview stream.
  • • Smart Toggle Guard (#allow-playlist): Automatically disables "Download Entire Playlist" on single-video URLs and enables it only on playlist links.

Local HTTP Server & Android JS Bridge Endpoints

Method Endpoint Purpose
GET /api/config Default save folder and runtime configuration
POST /api/info oEmbed preview, background duration resolution, and playlist pagination
POST /api/cancel-preview Immediately terminates active background playlist preview streams
POST /api/download Starts download job with format, quality, clip range, and subtitle options
GET /api/status Polls live %, MB/s speed, ETA, and playlist progress counters
POST /api/cancel Cancels active job and child FFmpeg process tree, cleaning up .part files
POST /api/pick-folder Opens native OS folder dialog or Android SAF directory picker
POST /api/open-folder Opens save folder and highlights the downloaded file in Explorer/Finder
GET /api/check-update Checks GitHub Releases for newer updates and release notes

Frequently Asked Questions (FAQ)

Does ClipHaven send any of my data or download history to external servers?

No. ClipHaven runs 100% locally on your device (127.0.0.1:8765) with zero ads, zero tracking, zero telemetry, and no external server relays.

Should I download the -All.zip bundle or the standalone binary on Desktop?

We recommend the All-in-One bundle (-All.zip) on Desktop. It comes pre-extracted with FFmpeg and all dependencies for instant startup and avoids antivirus false positives.

Do embedded subtitles stay in sync when I cut a specific clip from a video?

Yes! ClipHaven automatically trims .vtt/.srt subtitle cues to your [Start Time, End Time] window and shifts timestamps back by -Start Time so captions start at 00:00 in sync with the cut clip.
